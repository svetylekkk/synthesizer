# Сад звуков

Веб-инструмент для одного музыкального высказывания — короткой пьесы о том,
как в саду проходит день. Капли падают на цветы и звенят, ветер приносит смену
времени суток. Инструмент сделан под эту пьесу: в нём нет лишних ручек, только
то, что нужно, чтобы её сыграть, записать и переслушать.

Открыть: `index.html` в браузере (нужен интернет для Tone.js и шрифта).
Управление — в разделе «Интерфейс».

## Концепция

Четыре голоса сада — четыре роли в пьесе. Все в ре мажоре, поэтому любые
сочетания звучат согласно.

- **A «Капли»** — звонкие FM-колокольчики, мелодия. Восемь цветов на дуге —
  ноты пентатоники. Можно провести мышью/пальцем по цветам — будет перелив.
- **B «Ветер»** — мягкий пэд, гармония. Четыре облака — аккорды «времени
  суток»: рассвет (D), тень (Bm), полдень (G), закат (A). Звучит, пока держишь.
- **C «Сердце»** — бас, пульс. Касание — один удар, удержание — сердце
  бьётся «тук-тук» в темпе на корне аккорда.
- **D «Звёзды»** — арпеджио, мерцание. Пока держишь звезду, она перебирает
  ноты аккорда шестнадцатыми.
- **Солнце — время суток.** Его тянут по орбите: рассвет → полдень → закат →
  ночь. Одно движение меняет весь сад: яркость звука, количество «воздуха»
  (общий зал) и то, какой голос слышен сильнее — днём бьётся сердце, ночью
  выходят звёзды. Так пьеса получает драматургию: она проживает день.
- Сыгранное записывается и переслушивается — как ноты и движения солнца
  (через сам инструмент) и как аудиофайл.

## Структура звука

```
drops  FMSynth   → Filter → PingPongDelay → Reverb        → Channel L60 ─┐
wind   Synth     → AutoFilter → Chorus → Reverb           → Channel R60 ─┤
hearts MonoSynth → Distortion → Filter → Compressor       → Channel L15 ─┤
stars  Synth     → Vibrato → FeedbackDelay → Phaser       → Channel R30 ─┤
                                         (после каждого канала — Presence) ▼
              Day: Light (low-pass) → Air (reverb) → Master →
              выход · осциллограф в солнце · L/R · Recorder
```

У каждого голоса своя цепочка из трёх эффектов и свой канал
(громкость, панорама, mute). Ритмические голоса (сердце, звёзды) играют
циклами `Tone.Sequence` в общем темпе. Слой времени суток (`Presence` каждого
голоса + общий `Light` и `Air`) управляется солнцем; состояния четырёх часов
описаны в `SCORE.day`, между ними значения плавно смешиваются.

## Интерфейс

Горизонтальная сцена 1440×810, целиком масштабируется под окно:

| Зона | Что там |
| --- | --- |
| Шапка | подсказка клавиш · `Transport`: запись, слушать, стоп, время, аудио, заново · `Stepper` темпа |
| Сетка 2×2 | `VoicePanel` каждого голоса: сад-пэды + цепочка эффектов 1→4 |
| Центр | `Sun` — солнце на орбите суток, `DayStrip` — быстрый переход к часу, `MasterStrip` |
| Низ | `Timeline` — лента произведения: дорожка на каждый голос, подложка — цвет неба |

Сигнал в цепочке читается сверху вниз: звенья пронумерованы и соединены
связками. Подпись крутилки при наведении сменяется значением.

Управление: `A–K` — капли, `Z X C V` — облака, `1–4` — сердце, `7–0` —
звёзды, `R` — запись, `Space` — слушать/стоп. Крутилки: тянуть вверх-вниз,
стрелки клавиатуры, двойной клик — сброс. Солнце: тянуть по кругу или
стрелки, когда оно в фокусе; кнопки часов плавно переводят его.

## Стиль

Микс референсов: зерно, розово-красные цветы-«звёздочки» и сиреневая
дуга (blume) + белые обводки, плашки-теги, пастельные облака, контурные
сердца и четырёхлучевые звёзды (daho.design). Палитра «роза · сирень · небо»
с лаймовым акцентом ветра, шрифт Manrope. У каждого голоса свой цвет — он же
цвет его дорожки на ленте.
Все цвета, отступы и радиусы — токены в `styles/tokens.css`.

## Компоненты и нейминг

Компонент — функция в PascalCase, возвращает DOM-узел с одноимённым
CSS-классом по BEM: `Knob`, `Knob__Dial`, `GardenPanel--wind`.
Состояния — классы `is-active`, `is-playing`, `is-muted`, `is-dragging`.
Атрибут `data-param` — путь к параметру звука: `drops.filter.frequency`,
`wind.channel.pan`, `master.volume`.

- **UI-кит** (`scripts/components.js`, `styles/components.css`):
  `Pill`, `Button`, `ToggleButton`, `Stepper`, `Knob`, `Meter`,
  `EffectModule`, `EffectChain`, `ChannelStrip`
- **Сцена** (`scripts/scene.js`, `styles/scene.css`):
  `Pad` (`Flower`, `Cloud`, `Heart`, `Star`), `Garden` (`DropsGarden`,
  `WindGarden`, `HeartsGarden`, `StarsGarden`), `VoicePanel`, `Sun`,
  `DayStrip`, `MasterStrip`, `Transport`, `Timeline`
