# Сад звуков

Веб-инструмент для одного музыкального высказывания — короткой пьесы о том,
как в саду проходит день. Четыре голоса сада — капли, ветер, сердце и звёзды —
отвечают за мелодию, гармонию, пульс и мерцание. Солнце в центре ведёт время
суток от рассвета к ночи и меняет звучание всего сада, а лупер позволяет
выращивать пьесу слоями: записать мелодию и играть поверх неё.
